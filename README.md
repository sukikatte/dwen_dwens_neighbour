## 安装

```bash
# 克隆项目
git clone https://github.com/你的用户名/dwen_dwens_neighbour.git

# 进入项目目录
cd dwen_dwens_neighbour

# 创建虚拟环境
python -m venv .venv

# 激活虚拟环境
# Windows:
.venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt
```
